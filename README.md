# Bodegon D'Castillo

Web app para el catalogo y proceso de compra de Bodegon D'Castillo. Incluye vitrina de productos, carrito, checkout, panel administrativo, gestion de pedidos y conexion con Firebase.

## Funciones

- Catalogo filtrable por categorias.
- Imagenes de productos curadas por nombre para evitar fotos incorrectas.
- Carrito con flujo de pago y entrega.
- Panel admin para productos, categorias, pedidos y clientes.
- Autenticacion con Firebase Auth y datos en Firestore.

## Desarrollo

Requisitos: Node.js 22 o superior.

```bash
npm install
npm run dev
```

La app local corre por defecto en `http://localhost:7777`.

## Validacion

```bash
npm run lint
npm run build
```
